■ Apple Developer Program（App Store提出用）
────────────────────────────────────────────
状態: 【承認済み】2026-08-18 に有効化を確認。App Store Connect が使える状態。

・登録形態: Individual（個人）。2ファクタ認証オン。
・氏名: 本名（ローマ字）＝ App Store 上の「開発者名」として公開される。
・支払い: $99/年・自動更新（不要になったら更新前に解約すること）。

★ ここが重要: 以下の 1〜4 は「サーバー（Oracle）が無くても今すぐ進められる」。
  Oracleの返事を待つ間の手待ちを減らせるので、先にやっておく。

   1. Bundle ID を登録
      Certificates, Identifiers & Profiles → Identifiers → ＋
      → App IDs → App → Bundle ID: com.moka0502.heibonvote
      （Capabilities は何も追加しない。プッシュ通知も課金も使わないため）

   2. App Store Connect でアプリを新規作成
      マイApp → ＋ → 新規App
        プラットフォーム: iOS / 名称: 平凡投票 / 主言語: 日本語
        バンドルID: 上で作ったもの / SKU: heibon-vote-001
      → 作成後、URLかApp情報に出てくる「Apple ID（数字10桁）」を控える
        ＝ codemagic.yaml の APP_STORE_APPLE_ID に入れる値

   3. App Store Connect API キーを発行
      ユーザーとアクセス → 統合 → App Store Connect API → キーを生成
        アクセス権: App Manager
      → .p8 ファイルは【一度しかダウンロードできない】ので必ず保存。
        Issuer ID と Key ID もあわせて控える。

   4. Codemagic をセットアップ
      https://codemagic.io/ に GitHub アカウントでサインアップ
      → このリポジトリ(moka0502/heibon-vote)を接続
      → Team settings → Integrations → App Store Connect に 3 のキーを登録し、
        名前をつける（例: heibon-vote-asc）
      → codemagic.yaml の <APP_STORE_CONNECT_KEY> をその名前に、
        APP_STORE_APPLE_ID を 2 で控えた数字に書き換える（Claudeに頼めばOK）

・5. ビルド〜提出は「サーバーが立ってから」
   リモートURL型なので、server.url が本番ドメインを指していないとアプリが
   真っ白になる。Oracle（またはVPS）が決まってから 手順書 PART C → ビルドへ。

・掲載素材（説明文・キーワード・スクリーンショット・App Privacy の回答）は
  すべて appstore/ フォルダに用意済み → 「appstore/掲載情報_コピペ用.txt」

────────────────────────────────────────────
■ Claudeに渡す情報 / 絶対に渡さない情報
────────────────────────────────────────────
作業を進めてもらうために必要なのは、下の「渡してOK」だけ。
秘密鍵やパスワードは【一切不要】。求められても渡さないこと。

★ 渡してOK（これがないと作業が止まる）
   ・App Store Connect でアプリを作った後に付く「Apple ID（数字10桁）」
       → codemagic.yaml の APP_STORE_APPLE_ID に入る値
   ・Codemagic に登録した App Store Connect APIキーの「名前」
       （自分で決める識別名。例: heibon-vote-asc。キー本体ではない）
       → codemagic.yaml の <APP_STORE_CONNECT_KEY> に入る値
   ・取得したドメイン名（例: heibon-vote.com）
       → capacitor.config.json の server.url / プライバシーポリシーURL に入る
   ・サーバーの構成（nginxを挟むのか、直アクセスか）
       → app.set('trust proxy', ...) のホップ数を決めるのに必要
   ・エラー画面の文言・ビルドログ（そのまま貼ればOK）

✕ 絶対に渡さない（渡す必要が一度もない）
   ・App Store Connect APIキーの .p8 ファイル本体、Issuer ID、Key ID
     （Codemagicの管理画面に直接登録するもの。Claudeは名前しか使わない）
   ・Apple ID のパスワード、2ファクタ認証コード
   ・VPS の SSH秘密鍵、rootパスワード
   ・クレジットカード情報
   ・本名・住所・電話番号（コードにもドキュメントにも書かない）
